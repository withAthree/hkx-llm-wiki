# llm-wiki-ingest

LLM-Wiki 的摄入工作流。用户丢素材到 `raw/` 后，我自主扫描、拆解为原子知识单元、按领域分类入库、归档。

## 触发条件

**命令触发：** `!wiki ingest`
**自然语言触发：** 「收了这篇」「把这篇文章摄入」「把这个资料加进去」等

## 核心原则

**原子性：** 一个页面 = 一个不可分割的知识单元。一篇素材拆成多个原子页，各归各位。

**动态分类：** 编译时根据知识内容判断领域/类型，实时创建对应子目录。不预设目录结构。

## 编译约定

**子目录名也用中文。** 例如 `concepts/经济学/` 而不是 `concepts/economics/`。

### 概念 (wiki/concepts/)
判断知识的抽象领域，动态创建中文子目录。例如：
- 心理学知识 → `wiki/concepts/心理学/`
- 思维模型 → `wiki/concepts/思维模型/`
- 效率方法论 → `wiki/concepts/效率/`

**判断不出或跨领域 → 直接放 `wiki/concepts/` 根目录。**

### 实体 (wiki/entities/)
判断实体的类型，动态创建中文子目录。例如：
- 人物 → `wiki/entities/人物/`
- 书籍/文章 → `wiki/entities/书籍/`
- 公司/组织 → `wiki/entities/公司/`
- 工具/软件 → `wiki/entities/工具/`

**判断不出或新类型 → 直接放 `wiki/entities/` 根目录。**

### 来源摘要 (wiki/sources/)
始终放根目录，不再分子目录。

### 综合报告 (wiki/syntheses/)
始终放根目录，不再分子目录。

### 命名规则
- **概念/实体/来源页文件名：使用中文**（确保 Obsidian 图谱正常显示）
  - 例如：`长尾理论.md`、`心流.md`、`十分钟读懂金钱真相.md`
- 纯英文专有名词（PDF、RAG、Transformer）：用英文
- 子目录名用中文：`concepts/经济学/`

## 步骤

### 1. 自动扫描
扫描 `raw/` 下所有不在 `09-archive/` 的文件。排除 `.gitkeep`。
超过 10 个先问优先级。

### 2. 读取素材
- `.md` → 直接读取
- `.pdf` → 尝试提取文本，失败则记录元信息
- 非中文 → 自动翻译，原文备查
- 其他格式 → 跳过并报告

### 3. 拆解为原子知识单元
读完后拆解为：

**实体** — 人物、公司、工具、书籍等具体名词
**概念** — 方法论、框架、理论、模式等抽象知识
**观点** — 独特主张、论证、结论（仅当足够独立且有归档价值时）

### 4. 创建来源摘要页（薄层）
写入 `wiki/sources/来源文件名.md`：

```markdown
---
title: "来源文件名"
type: source
tags: [标签]
sources: [raw/xx/xxx.md]
last_updated: YYYY-MM-DD
---

## 核心主旨
[1-2句话]

## 本素材产出的知识单元
- [[蒋哥]] — 实体
- [[长尾理论]] — 概念

## 关联连接
```

### 5. 创建/更新原子知识页
对每个原子单元：

**① 判断领域/类型 → 确定目标子目录**
**② 子目录不存在 → 实时创建**
**③ 页面不存在 → 新建：**

```markdown
---
title: "知识单元名称"
type: entity | concept
domain: 领域名
tags: [标签]
sources: [十分钟读懂金钱真相]
last_updated: YYYY-MM-DD
---

## 定义
[一句话定义]

## 详情
[一个主题，保持聚焦]

## 关联连接
- [[十分钟读懂金钱真相]] — 来源
- [[投资底层逻辑]] — 相关内容
```

**页面已存在 → 增量合并。** 只加新信息，不重复。

### 6. 冲突处理
当新内容与已有页面冲突时：

1. **暂停** — 停止当前 ingest
2. **报告** — 冲突页面、冲突内容
3. **用户选 A/B/C：**
   - A) 保留两者 → 在页面中标记 `## 知识冲突`
   - B) 新知识覆盖旧知识
   - C) 放弃本次 ingest
4. **继续**

### 7. 更新索引
在 `wiki/index.md` 对应分类下新增条目：

```
### wiki/sources/
- [[十分钟读懂金钱真相]] — 核心主旨

### wiki/concepts/
- [[经济学/货币共识理论]] — 定义

### wiki/entities/
- [[人物/孟岩]] — 定义
```

### 8. 记录日志
```
## [YYYY-MM-DD] ingest | 标题

- 来源：raw/路径
- 新原子页：人物/蒋哥, 经济学/货币共识理论
- 更新页：page3
- 冲突：无
```

### 9. 归档
源文件移入 `raw/09-archive/`。

### 10. 完成后一次性报告
```
📥 Ingest 完成 — 素材名
├── 实体：N 个 (人物/蒋哥, 公司/Zion)
├── 概念：N 个 (经济学/货币共识理论, 投资/指数基金)
├── 更新：N 个
└── 冲突：无
```

## 约束
- 绝不修改源文件
- 绝不读取 `raw/09-archive/`
- 绝不修改 `SCHEMA.md`
- 一个页面只负责一个知识单元
- 来源中没有的用 `TODO` 标记
- 领域/类型判断不清时，放父目录而非强行分类
